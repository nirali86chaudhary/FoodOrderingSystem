🌟 Personal Profile & Digital Identity Project

Human Blueprint is a modern web-based project created to present personal and professional information in a structured, clean, and visually appealing format.

✨ Features

- 👤 Personal Profile
- 🎓 Education Details
- 💻 Technical Skills
- 🚀 Projects & Work
- 📋 Organized Information
- 📱 Responsive Design
- 🎨 Clean & Professional UI

🛠️ Technologies

- 🌐 HTML5
- 🎨 CSS3
- ⚡ JavaScript

🎯 Objective

The goal of Human Blueprint is to create a digital representation of an individual that combines personal information, education, skills, and projects into one organized platform.
